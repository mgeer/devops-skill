## 前置修复记录

### 1. validate-devops-yaml.sh macOS 兼容性

**文件:** `gitops-repo/schemas/validate-devops-yaml.sh` 第 36-37 行

```bash
# 修复前（macOS 不支持 grep -oP）:
TYPE=$(echo "${line}" | grep -oP 'type:\s*\K\S+' || true)
ROLE=$(echo "${line}" | grep -oP 'role:\s*\K\S+' || true)

# 修复后:
TYPE=$(echo "${line}" | awk -F'type:' '{print $2}' | awk '{print $1}')
ROLE=$(echo "${line}" | awk -F'role:' '{print $2}' | awk '{print $1}')
```

### 2. detect-drift.sh containerPort 提取 bug

**文件:** `gitops-repo/schemas/detect-drift.sh` 第 56 行

```bash
# 修复前（YAML list 前缀 `-` 导致 awk 取错字段）:
DEPLOY_PORT=$(grep 'containerPort:' ... | awk '{print $2}')

# 修复后:
DEPLOY_PORT=$(grep 'containerPort:' ... | awk -F'containerPort:' '{print $2}' | awk '{print $1}')
```

### 3. detect-drift.sh healthcheck 路径提取 bug

**文件:** `gitops-repo/schemas/detect-drift.sh` 第 62 行

```bash
# 修复前（grep -A1 不够深，set -e 导致退出）:
DEPLOY_HEALTH=$(grep -A1 'livenessProbe:' ... | grep 'path:' | awk '{print $2}')

# 修复后:
DEPLOY_HEALTH=$(grep -A3 'livenessProbe:' ... | grep 'path:' | head -1 | awk '{print $2}' || true)
```
